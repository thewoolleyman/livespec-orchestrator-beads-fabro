## Proposal: A misjudged spec-change-tier hold has a human way through: an attested release that later judgements honour while the attested input and cited clause are unchanged

### Target specification files

- SPECIFICATION/contracts.md
- SPECIFICATION/scenarios.md

### Summary

Adds a human-only `release-spec-tier:<work-item-id>:<heading>` valve to touchpoint 1. A human names an existing H2 heading and attests that it states the held item's asked-for behaviour. The valve refuses a heading that does not resolve, an item that is not held, a live run and a live ownership lock. It records the attestation in a ledger comment and a dispatch-journal entry, clears the hold, and routes through the existing journaled doors; a pending-rework item stays active. Every later taking, the pre-dispatch wall and dod_gate included, uses the attested stated verdict while the attested input and the cited clause are unchanged, with the cited clause as clause provenance. The shared-judgement paragraph names this as its one exception. The valve is listed in the backlog, pending-approval, ready, blocked and active lane rows, and Scenario 206 gains four cases.

### Motivation

From the spec-implementation-lockstep plan (epic bd-ib-ax3rds). Maintainer ruling 2026-10-27: no item may be left with no way through because the spec-stated judgement misjudged it. The touchpoint-1 hold releases a held feature only when its linked proposal is ratified AND a re-run judgement returns stated, 'with no human valve'. So a miss on an existing clause is an unbounded hold: a proposal restating that clause can be rejected, and even a ratified one can be re-held by another miss. This holds today at the 200,000-character prompt ceiling. The attested-release shape was chosen in this session's picker; coordinator gitops-fleet-capacity-monitoring reports that it gave that answer under its standing authorization R118. bd-ib-57ss2n carries a dispatch hold until this lands. Three read-only gpt-6-astra review rounds: round 1 raised three blockers (the verb tables, journaled doors, and the attestation as an explicit exception to the shared-judgement rule), round 2 one (pending-rework items in active), all folded in; round 3 returned NO BLOCKERS.
